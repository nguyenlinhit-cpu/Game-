# Game Design & Assets

Tài nguyên thiết kế (Design Assets), glyphs, biểu tượng (Creed, Aspect), và mã nguồn dựng icon cho dự án game.

## Cấu trúc thư mục

- `Design/Aspect/`: Glyphs & Icons thuộc tính/nguyên tố (Might, Ember, Frost, Storm, Gale, Rift, Chrono) dạng SVG & PNG kèm script build.
- `Design/Creed/`: Biểu tượng Creed (Fury, Pursuit, Ruin, Chorus, Decay, Bastion, Vitality) kèm file Blender 3D (`.blend`), render PNG và preview.
- `Design/Character/`: Thiết kế nhân vật chính (Male / Female).
- `Design/Enemies/`: Thiết kế quái vật / kẻ địch.
- `Design/Map/`: Bản đồ và môi trường.
